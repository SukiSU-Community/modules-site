      如果已收录模块存在未经用户同意的行为，可以在此举报。唯一硬性要求是： 以本人酷安账号署名举报，并且能在模块包中逐字找到所引用的内容。未找到引用内容时， 记录会判定为「与模块包内容不符」，不构成对作者的指控。

      打开酷安「我的 → 编辑资料 → 个性签名」，粘贴上方签名串并保存，然后返回提交。 该签名串与被举报模块及模块包校验值绑定，更换模块或版本后会变化。 它用于证明该账号归你所有；公示流程仅接受此凭据。

      提交成功后该签名串即失效；如需举报其他模块，请点击「更换签名串」重新生成。

      后续提交后的处理流程

      提交本身不会改动模块库。无论举报是否成立，都会先记入待办； 此处会显示为「模块库未做任何改动」。

      随后由自动流程处理：定时将待办生成公示记录，再由自动检查独立获取归档模块包， 逐字核对引用内容是否确实存在于包中。核实成立后才会下架，并在本页公示。 全程没有人工审批：结论只取决于证据是否成立。

      举报的频率限制分别按 IP 与账号计算，与上传次数分开；举报不占用上传次数，上传也不占用举报次数。

      全部记录 上方按上传者分组，仅包含已核实身份的记录；此处列出全部记录，并按原因归类。

      申诉对处置结果有异议时

      正式渠道仅有模块库仓库的 issue（议题）。模块被下架时，请在议题中说明具体哪一项判定有误， 并附上证据；审核未通过、未被收录的情况，请在对应的上传说明中说明。

      每条下架记录都标明由哪一次自动检查判定，旁边的命令可由任何人重新执行核对。 本站没有人工审批，全部由自动检查完成；如需推翻结论， 请提交可被该检查验证的证据。

      本站不承诺回复时限，也不承诺一定回复。可以保证的是：每次放行或下架都会留下可查的运行记录与证据， 判定来源始终可追溯。酷安私信与评论仅供参考；只有议题中的材料会纳入处理。

      图例术语说明

        为什么需要这个站

        它只解决一个具体问题：好模块难以发现，找到了也常常下载失败。

        A好模块并不少

        KernelSU 与 Magisk 的模块都是 ZIP 文件，管理器从模块库读取， 因此可以浏览并一键安装。但许多国内作者制作的模块不在任何模块库中： ZIP 放在网盘，帖子里发一个链接，用户下载后手动刷入。

        1. 正式仓库接收门槛高。要求模块 ID 与仓库名一致，且只有仓库所有者可以提交；个人项目通常不符合这些条件。
        2. 网盘链接容易失效。有效期限制、需要转存、分享账号被封，几个月后帖子里只剩一个无法打开的页面。
        3. 难以搜索。模块库中没有条目，只能依赖口口相传；用过的人知道，新用户找不到。

        B上传之后会发生什么

        尚未收录的模块可以由符合要求的用户上传。流程固定如下：

        1. 1
          上传模块包由本站接收并保存。
        2. 2
          保存为长期下载地址托管在 GitHub 上，提供稳定下载，替代容易失效的网盘链接。
        3. 3
          自动提交审核只提交模块信息，不包含 ZIP 文件。
        4. 4
          自动检查检查脚本中的危险操作、未声明联网和敏感信息。
        5. 5
          更新仅限归属人已收录模块只接受首次上传该模块的酷安账号提交新版本，判定标准与首次上传相同。
        6. 6
          进入公共模块库管理器可以搜索到，下载地址长期有效。
        上传完成不等于立即收录。新模块与更新使用同一套自动检查： 通过后自动收录；未通过时会停在检查环节，等待修改后重新提交。 更新还多一项限制：仅归属人可以发布。否则他人可以复刻热门模块、 加入恶意代码并伪装成更新，已安装的用户会收到恶意版本。 归属人身份以首次上传的酷安账号为准；更换账号上传同一模块会被视为其他上传者。

        C两种入口

        在手机上使用管理器 App，选择本地 ZIP 时会提示上传。
        在电脑上，或由作者本人操作时，使用本网页。

        D为什么要求填写酷安 UID

        模块库公开，任何人都可以提交内容，因此最关键的是能够找到上传者。 昵称可以随意填写，酷安 UID 唯一，打开主页即可确认账号身份，平台也可以处理违规账号： 出现问题时，打开 coolapk.com/u/<UID> 即可核对；社区也可以对具体账号采取措施。

        来源同样只接受酷安站内链接：模块必须能追溯到具体帖子或作者主页； 网盘直链与匿名转存不计为来源。源码只接受 GitHub 上的公开仓库。两项至少填写一项。

        昵称与 UID 不同。昵称用于展示，会显示在列表中；UID 用于核实与追责。 UID 填写正确时，系统会核实账号是否存在，并自动填入昵称。
